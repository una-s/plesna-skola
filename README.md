# Plesna škola

Klijent-server aplikacija razvijena u okviru predmeta **Projektovanje softvera**.
Implementirana po **MVC (Model-View-Controller)** arhitektonskom obrascu.

---

## Tehnologije

- Java
- MySQL

---

## Struktura projekta

```
├── 1_SEMINARSKI_KLIJENT/     # Klijentska aplikacija
├── 1_SEMINARSKI_SERVER/      # Serverska aplikacija
├── 1_SEMINARSKI_ZAJEDNICKI/  # Zajednički modeli i klase
└── baza.sql                  # SQL skripta za inicijalizaciju baze
```

---

## Pokretanje

1. Importovati bazu podataka: `baza.sql`
2. Pokrenuti `1_SEMINARSKI_SERVER`
3. Pokrenuti `1_SEMINARSKI_KLIJENT`
